# 🇮🇳 India UPI Transactions Analytics Dashboard

### Interactive Data Analytics Project | January 2021 – September 2026

## 📊 Project Overview

This project analyzes India's Unified Payments Interface (UPI) transaction trends from January 2021 to September 2026.

An interactive dashboard was developed using Python, Pandas, Plotly, and Streamlit to explore transaction volumes, transaction values, banking participation, and growth trends.

## 🛠️ Technologies Used

- **Python** – Data analysis and application development
- **Pandas** – Data cleaning and manipulation
- **Plotly** – Interactive data visualization
- **Streamlit** – Interactive dashboard development
- **SQL / MySQL** – Database management and querying
- **GitHub** – Version control and project hosting

## ✨ Dashboard Features

- Interactive navigation with five analytical sections
- Year-wise transaction filtering
- Six key performance indicators (KPIs)
- Monthly and yearly transaction trend analysis
- Month-over-Month (MoM) and Year-over-Year (YoY) growth analysis
- Banking participation analysis
- Average transaction value analysis
- Filtered dataset exploration and CSV download

## 📈 Key Insights

- **Total Transaction Volume:** 836.16 Billion
- **Total Transaction Value:** ₹1,188.68 Trillion
- **Active Banks (September 2026):** 756
- **Average Transaction Value:** ₹1,422
- **Peak Year-over-Year Volume Growth:** +134.5%

*These figures represent the full dataset from January 2021 to September 2026.*

## 🚀 How to Run the Dashboard

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```
